## T AI — Personal RAG Assistant

A Retrieval-Augmented Generation assistant built directly into this portfolio.

T AI allows visitors to explore my professional experience, technical skills, projects, certifications, and AI services through natural-language conversation.

Instead of relying only on an LLM's general knowledge, T AI retrieves relevant information from a dedicated portfolio knowledge base before generating an answer.

**Architecture**

Knowledge Base → Chunking → Embeddings → Vector Search → Context Retrieval → LLM → Answer + Sources

**Technologies**

Python · FastAPI · Next.js · TypeScript · LLM APIs · RAG · Embeddings · Supabase · PostgreSQL · pgvector
